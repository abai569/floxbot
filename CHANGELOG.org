# Changelog

This file summarizes the most important changes for each release.
* Version 1.3.0 (2026-10-03)
  - Lower the production spam probability threshold from 0.94 to 0.85 so high-confidence advertisements are deleted.

* Version 1.2.9 (2026-07-08)
  - Use flex layout for trained message filters so all 6 fields stay on one row.
  - Translate search label to Chinese.

* Version 1.2.8 (2026-07-08)
  - Force login card width with inline style to bypass Tailwind build cache.

* Version 1.2.7 (2026-07-08)
  - Compact trained message filter row into a single line with smaller labels and tighter spacing.
  - Narrow login page card for a cleaner centered look.

* Version 1.2.6 (2026-07-08)
  - Fix classifier never deleting spam because maybe_ham samples were excluded from training.
  - Expand trainable scope to include maybe_spam and maybe_ham so the Bayesian classifier has ham data.
  - Treat maybe_spam as spam and maybe_ham as ham in train_only for correct class counting.
  - Handle maybe_spam and maybe_ham in handle_existing_message hash cache lookups.
  - Sync message_type_sync_job and controller to trigger retraining for maybe types.

* Version 1.2.5 (2026-07-08)
  - Unify edit and new form action buttons into one bottom-right button group.
  - Move remaining trained message, banned user, and group classifier submit buttons out of the form card.
  - Shorten Chinese action labels to match the compact admin button style.

* Version 1.2.4 (2026-07-08)
  - Center admin form and detail pages with a consistent max-width container.
  - Move form and detail action buttons to the bottom-right for easier access.
  - Apply the same action placement to trained messages, group configs, keyword replies, banned users, and group classifier states.

* Version 1.2.3 (2026-07-08)
  - Align the header width with the main content container.
  - Move group configuration and keyword reply form actions into the page header.
  - Improve admin action buttons with compact pill styling across table and mobile card views.
  - Fix blank submit buttons caused by generic input styling.
  - Make trained message bulk selection obvious on desktop and mobile.

* Version 1.2.2 (2026-07-08)
  - Refresh the admin interface with a unified visual system for navigation, cards, buttons, forms, tables, and flash messages.
  - Redesign the login page and group configuration views for clearer information hierarchy.
  - Add mobile-first card layouts for group configs, banned users, keyword replies, and classifier states.
  - Improve group configuration forms with sectioned cards, helper text, and a clearer mobile submit flow.

* Version 1.2.1 (2026-07-08)
  - Fix /feedspam samples being saved as maybe_spam instead of spam, preventing them from training the classifier.
  - Add a safe default for channel_broadcast_blacklist so spam analysis no longer crashes before enqueueing.
  - Show a clear reply-required message when /markspam is used without replying to a spam message.
  - Add regression tests for /feedspam training, /markspam usage feedback, and channel broadcast blacklist defaults.

* Version 1.2.0 (2026-06-22)
  - Add per-group Bot language selector in the group configuration panel.
  - Localize new-member verification messages for button and math verification modes.
  - Replace cleanup checkboxes with unified minute-based cleanup delays.
  - Add cleanup delays for alert messages, keyword replies, forwarded messages, and welcome messages.
  - Automatically clean up group command messages and bot operation notices according to the alert cleanup delay.
  - Add migrations for group language and cleanup delay fields.

* Version 1.1.0 (2026-05-22)
  - Automatically delete start message to avoid polluting the chat
  - Add support for banning guest bot spamming, if a user use guest bot to send spam message, the user who mentioned the bot will be banned
  - Prevent users from flooding the bot in group chats. If a  user sends multiple /start commands within this window(10s), subsequent commands are ignored.
