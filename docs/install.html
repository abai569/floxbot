1. 前置条件

1.1 服务器要求
项目要求
系统Ubuntu 20.04+ / Debian 11+ / CentOS 8+（推荐 Ubuntu 22.04）
CPU1 核即可
内存512MB 起步，推荐 1GB
磁盘10GB 可用空间
网络能访问 GitHub 和 Telegram API
1.2 安装 Docker

如果服务器还没装 Docker，执行以下命令：

Shell — 一键安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh && sudo sh get-docker.sh

安装完成后验证：

Shell — 验证 Docker
docker --version
docker compose version
需要 Docker 20.10+ 和 Docker Compose v2+。如果 docker compose 报错，参考 官方文档。
1.3 创建 Telegram Bot
  1. 打开 Telegram，搜索 @BotFather
  2. 发送 /newbot
  3. 按提示输入 Bot 名称和用户名（用户名必须以 bot 结尾）
  4. 保存返回的 Token（格式类似 123456789:ABCdefGHIjklMNOpqrsTUVwxyz）
  5. 发送 /setprivacy → 选择你的 Bot → 选 Disable（让 Bot 能接收群内所有消息）
  6. 发送 /setcommands → 选择你的 Bot → 粘贴以下命令列表：
BotFather 命令列表
start - 查看帮助
markspam - 标记广告并封禁（回复消息使用）
feedspam - 投喂广告文本训练
listspam - 查看被删广告列表
listbanuser - 查看封禁用户列表
setverify - 设置入群认证模式
setwelcome - 设置欢迎辞文本
setwelcome_photo - 设置欢迎图片
setwelcome_video - 设置欢迎视频
setwelcome_btn - 设置欢迎按钮
addkeyword - 添加关键字回复
delkeyword - 删除关键字回复
listkeywords - 列出关键字回复
set - 快捷开关清理选项
help - 查看帮助

2. 首次安装

2.1 拉取代码
Shell — 克隆仓库
cd ~
git clone https://github.com/abai569/floxbot.git
cd floxbot
仓库是 Private 的。如果 VPS 上的 Git 没配过 GitHub 认证，使用 Token 方式：
Shell — 带 Token 克隆
git clone https://你的GitHub用户名:你的Token@github.com/abai569/floxbot.git
cd floxbot

3. 配置 .env

3.1 创建 .env 文件
Shell — 复制模板
cp .env.example .env

编辑 .env，填入以下内容：

.env — 配置文件
# 必填：从 @BotFather 获取的 Token
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# 必填：管理面板登录账号密码
ADMIN_USERNAME=admin
ADMIN_PASSWORD=你的强密码

# 可选：管理面板端口（默认 8060）
PORT=8060
注意：
  • ADMIN_PASSWORD 必须设置，否则无法登录管理面板
  • 不要用默认密码，建议用随机字符串（至少 12 位）
  • .env 文件不会被提交到 Git（已在 .gitignore 中）

4. 启动 Bot

4.1 构建并启动
Shell — 首次启动
docker compose up -d --build

首次构建需要 3~5 分钟（下载 Ruby 依赖、编译 gems）。后续启动只需几秒。

查看运行状态：

Shell — 查看容器状态
docker compose ps

查看日志（按 Ctrl+C 退出日志查看）：

Shell — 查看日志
docker compose logs -f bot
4.2 验证启动成功
  1. 浏览器打开 http://你的VPS_IP:8060 → 弹出登录框 → 输入 .env 中的账号密码 → 看到管理面板 = 成功
  2. 在 Telegram 给 Bot 发 /start → Bot 回复欢迎消息 = Bot 正常工作
  3. 把 Bot 加入群 → 给 Bot 管理员权限（删除消息 + 封禁用户）→ 开始自动拦截广告

5. 管理面板使用

5.1 页面导航
页面路径功能
Trained Messages/trained_messages查看/管理训练数据，批量标记广告或正常消息
Group Classifiers/group_classifier_states查看各群贝叶斯模型状态、高频词分析
Banned Users/banned_users查看/解封被封禁的用户
Group Configs/group_configs配置各群的认证模式、欢迎辞、清理开关
Keywords/keyword_replies管理关键字回复规则
Mission Control/jobs查看后台任务队列状态
5.2 配置群组（Group Configs）

点击 Group Configs → New group config 或编辑已有配置：

字段说明
Group ID群 ID（负数，如 -100123456789）。可在群内发 @RawDataBot 获取
Verification Modenone 不验证 / button 按钮验证 / math 数学题验证
Timeout验证超时时间（秒），默认 60
Welcome Text欢迎辞文本，支持 {name} 和 {title} 变量
Welcome Photo欢迎图片的 file_id（在群内发图给 Bot，Bot 会回复 file_id）
Welcome Video欢迎视频的 file_id
Welcome ButtonsJSON 数组，如 [{"text":"频道","url":"https://t.me/xxx"}]
Delete Forwards自动删除转发消息
Delete Keyword Triggers删除触发关键字回复的用户消息
5.3 配置关键字回复（Keywords）

点击 Keywords → New keyword reply：

字段说明
Group ID所属群 ID
Keyword触发关键字
Reply Typetext 文本 / photo 图片 / video 视频
Reply Content回复内容（文本回复填文字，图片/视频填 file_id）
Caption图片/视频回复时附带的文字说明
Exact match精确匹配（消息内容完全等于关键字）
Regex match正则匹配
都不选包含匹配（消息包含关键字即触发）

6. Bot 命令参考

6.1 广告管理
命令权限说明
/markspam管理员回复一条消息使用，删除该消息 + 封禁发送者 + 标记为广告训练模型
/feedspam任何人投喂广告文本训练模型（可回复消息或直接跟文本）
/listspam管理员查看被删广告列表，可标记为正常（纠正误判）
/listbanuser管理员查看封禁列表，可解封用户
6.2 群组设置
命令权限说明
/setverify none管理员关闭入群验证
/setverify button管理员按钮验证模式
/setverify math管理员数学题验证模式
/setwelcome 文本管理员设置欢迎辞（支持 {name} {title}）
/setwelcome_photo管理员回复一张图片给 Bot 设置欢迎图
/setwelcome_video管理员回复一个视频给 Bot 设置欢迎视频
/setwelcome_btn管理员设置欢迎按钮 JSON
6.3 关键字回复
命令权限说明
/addkeyword 关键字 -> 回复内容管理员添加关键字回复
/delkeyword 关键字管理员删除关键字回复
/listkeywords管理员列出所有关键字回复
6.4 消息清理
命令权限说明
/set del_forward on管理员自动删除转发消息
/set del_forward off管理员关闭转发删除
/set del_keyword on管理员删除触发关键字的用户消息
/set del_keyword off管理员关闭关键字触发删除

7. 升级更新

7.1 常规升级（推荐）

每次有新代码推送到 GitHub 后，在 VPS 上执行：

Shell — 一键升级
cd ~/floxbot
git pull
docker compose up -d --build

这会拉取最新代码、重新构建镜像、重启所有容器。数据库迁移会自动执行。

7.2 仅重启（不重新构建）

如果只是修改了 .env 或想重启服务（不拉新代码）：

Shell — 重启服务
cd ~/floxbot
docker compose restart
7.3 完全重建（清理旧镜像）

如果升级后有问题，可以清理旧镜像重新构建：

Shell — 清理重建
cd ~/floxbot
docker compose down
docker compose build --no-cache
docker compose up -d
7.4 查看当前版本
Shell — 查看最近提交
cd ~/floxbot
git log --oneline -5

8. 常见问题

Q: 管理面板打不开
Shell — 排查步骤
# 1. 检查容器是否运行
docker compose ps

# 2. 检查端口是否监听
ss -tlnp | grep 8060

# 3. 检查防火墙是否放行
sudo ufw allow 8060/tcp

# 4. 查看 app 容器日志
docker compose logs app
Q: Bot 不回复消息
Shell — 排查步骤
# 1. 查看 bot 容器日志
docker compose logs bot

# 2. 确认 .env 中 TELEGRAM_BOT_TOKEN 正确
cat .env | grep TOKEN

# 3. 重启 bot 容器
docker compose restart bot
Q: 数据库迁移失败
Shell — 手动迁移
docker compose exec app bin/rails db:migrate
Q: 如何备份数据
Shell — 备份 SQLite 数据库
# 找到数据库文件位置
docker compose exec app find /rails/storage -name "*.sqlite3"

# 复制到宿主机
docker compose cp app:/rails/storage/production.sqlite3 ./backup_$(date +%Y%m%d).sqlite3
